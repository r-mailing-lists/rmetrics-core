# rmetrics-core

Maintainers of the Rmetrics packages

Automated mbox archive. Updated daily via GitHub Actions.

## Structure

- `raw/` - Monthly .mbox files downloaded from [https://stat.ethz.ch/pipermail/rmetrics-core/](https://stat.ethz.ch/pipermail/rmetrics-core/)
- `processed/` - Structured JSON output from rmail-parser
- `meta.json` - List statistics

## Viewer

Browse these archives at [archives.rstats.dev](https://archives.rstats.dev/lists/rmetrics-core/)
